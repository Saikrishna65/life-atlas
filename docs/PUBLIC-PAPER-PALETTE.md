# Shared public paper palette

The Trip Archive's #eeefec canvas is now the public site's shared background.
`public-theme.css`, imported unlayered by world.css, scopes tokens and contrast
adjustments to .living-world and its public portals. Private app routes have no
matching root and receive no colour overrides. Hero/video pixels and the native
globe renderer are unchanged. Map tiles and media stay independent environments.

Landing sections, public collection wrappers, trip detail reading sections and
public photo viewers use dark ink, muted green text and visible green focus
outlines on paper. White navigation artwork retains its charcoal backplate.
The closing door's geometry and animation are preserved with a light backdrop.

Numbered ChapterLabel bars, decorative dividers and their right-side captions
were removed from all public scene components, including unused/reusable scenes.
Main headings, meaningful form controls, photo metadata and provenance remain.
