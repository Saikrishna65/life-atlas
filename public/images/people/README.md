# Illustrative people photography

Eight fictional travel portraits/group scenes generated with OpenAI Image Generation
on 2026-11-16 for the public Life Atlas sample collection. No photographed person
is represented as the site owner's acquaintance. These are not personal trip
records. Disclosure appears both in the section and its viewer.

A single original 4-by-2 photographic sheet was separated into eight local WebP
assets (no remote image dependency). Original reference is held in the task's
workspace generated_images directory; production assets are these WebP files.
No external stock photos were downloaded or used; network requests to stock hosts
were blocked. Data/order: src/data/demo/people.ts. No private app, upload, vault or
publishing integration is implemented in this change.
